fanfou-mcp

An MCP server for Fanfou (饭否) that lets your AI assistant read your timeline.

fanfou-mcp connects Fanfou to Claude Desktop, Cursor, Grok Bot and other clients through the Model Context Protocol. It runs locally over stdio, or remotely over Streamable HTTP — for example on Vercel.

Features

  • 11 read-only tools: home timeline, mentions, user timelines, search, statuses, conversation context, users and favorites.
  • 4 write tools — post, delete, favorite, follow — each requiring an explicit confirm=true.
  • Set FANFOU_MCP_READONLY=1 to leave the write tools out entirely. The HTTP server is read-only by default.
  • Bearer token authentication for the HTTP endpoint.
  • Stateless JSON responses, suited to serverless hosting.

Quick start

Requires uv and Python 3.12 or later.

git clone https://github.com/Anthonyeef/fanfou-mcp.git
cd fanfou-mcp
uv sync

Then add it to your client’s mcp.json:

{
  "mcpServers": {
    "fanfou": {
      "command": "uv",
      "args": ["run", "--directory", "/path/to/fanfou-mcp",
               "python", "server.py"],
      "env": {
        "FANFOU_API_KEY": "<consumer_key>",
        "FANFOU_API_SECRET": "<consumer_secret>",
        "FANFOU_OAUTH_TOKEN": "<access_token>",
        "FANFOU_OAUTH_TOKEN_SECRET": "<access_token_secret>",
        "FANFOU_MCP_READONLY": "1"
      }
    }
  }
}

Remove FANFOU_MCP_READONLY to enable the write tools. Deployment to Vercel is covered in the README.

Notes

  • You need the key of a Fanfou app that has already been approved. Fanfou has been whitelist-only since 2020 and no longer accepts new applications; no key is included.
  • OAuth 1.0a signatures use the http:// URL in the base string, while requests are sent over https://.
