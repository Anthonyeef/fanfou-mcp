fanfou-mcp

An MCP server for Fanfou (饭否). Use the hosted instance — authorize in the browser and connect.

fanfou-mcp connects Fanfou to Claude Desktop, Cursor, Grok Bot and other clients through the Model Context Protocol. It runs locally over stdio, or remotely over Streamable HTTP. A hosted multi-user instance is available: open a link, approve Fanfou access, and paste the token into your client.

Features

  • Multi-user hosting: /authorize → approve on Fanfou → a personal ffm_ token for your own timeline.
  • 11 read-only tools: home timeline, mentions, user timelines, search, statuses, conversation context, users and favorites.
  • 4 write tools — post, delete, favorite, follow — each requiring an explicit confirm=true.
  • Set FANFOU_MCP_READONLY=1 to leave the write tools out entirely. The HTTP server (and the hosted instance) is read-only by default.
  • Bearer token authentication for the HTTP endpoint.
  • Stateless JSON responses, suited to serverless hosting.

Quick start

Use the hosted instance

  1. Open https://fanfou-mcp.vercel.app/authorize and approve access on Fanfou.
  2. Copy the personal token and the config snippet shown on the next page (shown once).

Point your MCP client at https://fanfou-mcp.vercel.app/mcp with Authorization: Bearer <your ffm_ token>.

Self-host

Requires uv and Python 3.12 or later.

git clone https://github.com/Anthonyeef/fanfou-mcp.git
cd fanfou-mcp
uv sync

Then add it to your client’s mcp.json:

{
  "mcpServers": {
    "fanfou": {
      "command": "uv",
      "args": ["run", "--directory", "/path/to/fanfou-mcp",
               "python", "server.py"],
      "env": {
        "FANFOU_API_KEY": "<consumer_key>",
        "FANFOU_API_SECRET": "<consumer_secret>",
        "FANFOU_OAUTH_TOKEN": "<access_token>",
        "FANFOU_OAUTH_TOKEN_SECRET": "<access_token_secret>",
        "FANFOU_MCP_READONLY": "1"
      }
    }
  }
}

Remove FANFOU_MCP_READONLY to enable the write tools. Remote and multi-user deployment is covered in the README.

Notes

  • Self-hosting still needs the key of a Fanfou app that has already been approved — Fanfou has been whitelist-only since 2020. Users of the hosted instance do not need their own key.
  • OAuth 1.0a signatures use the http:// URL in the base string, while requests are sent over https://.
